# Repository header labels

Show all local repository labels below the package/URL/commit block on the
Status page. Use the overview palette and safe service DTO mapping. Untagged
repositories have no label row; multiple/long labels wrap. Native Links offer
keyboard access. Clicking a label leaves Status and returns to the overview
with an exact label filter, validated against its freshly loaded rows.

No label persistence or abapGit references in app state. Offline repositories
also show labels; leaving clears their uploaded ZIP as Back does.
