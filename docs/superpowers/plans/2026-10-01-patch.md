# Patch (staging single lines): implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Commit only the picked lines of a locally changed file from the staging page.

**Architecture:** The diff page gets a patch mode with one checkbox per
changed line. Both halves of a changed line share one patch ID. The staging
page keeps the picked IDs plus a fingerprint of the diff. On push the service
recomputes the diff, checks the fingerprint, sets abapGit's `patch_flag` per
ID, and stages the output of `zcl_abapgit_git_add_patch`.

**Tech Stack:** ABAP 7.5x on A4H25, abapGit developer version, abap2UI5
1.146.0, abaplint plus abap2ui5lint (`npm run check`).

**Spec:** `docs/superpowers/specs/2026-10-01-patch-design.md`

## Global Constraints

## Review Focus

1. **A file without a final newline.** `get_patch_binary( )` always appends
   a newline. Expect the same result as abapGit: the pushed file ends in a
   newline. Pinned in Task 1 (`patch_content_no_final_newline`).
2. **A stale selection.** The file changed after the lines were picked, by an
   edit in the system or a push from elsewhere. Expect `changed`, with nothing
   pushed. Pinned in Task 2 (smoke test with an edited fingerprint), and by
   `apply_patch` raising on unknown IDs in Task 1.
3. **A file deleted locally (`D` / `RM`) with only some lines picked.** Expect
   `add` as modified, and the file stays in Git with the unpicked lines.
   Pinned in Task 1 (`patch_action` matrix, `patch_content_partial_delete`).
4. **Returning from the read-only diff.** Back from a normal diff (not patch
   mode), or Back without Apply, must not change the row. Pinned in Task 4
   (`back_without_apply_keeps_row`).
5. **Toggling "Show all" / "Changes only" after picking.** The picks must
   survive the rebuild of the rows. Pinned in Task 3 (`picks_survive_toggle`).

**One deviation from the spec:** the staging page does not know whether a
file is binary (`get_stage` does not read file content). "Pick lines" is
therefore offered on every row except deletions of binary files. The diff
page in patch mode shows "Binary file - no line diff" and **no Apply**, so a
binary file still cannot be patched.

### Task 1: Patch IDs, fingerprint, apply_patch, patch_action (side-effect free)

**Files:**
- Modify: `src/zif_ag2ui5_repo_service.intf.abap` (types `ty_diff_line`, `ty_diff`)

**Interfaces:**
- Produces:
  - `zif_ag2ui5_repo_service=>ty_diff_line-patch_id TYPE string`
  - `zif_ag2ui5_repo_service=>ty_diff-fingerprint TYPE string`
  - `zcl_ag2ui5_repo_service=>fingerprint( iv_local TYPE xstring iv_remote TYPE xstring ) RETURNING rv_fingerprint TYPE string RAISING zcx_abapgit_exception`
  - `zcl_ag2ui5_repo_service=>apply_patch( it_diff TYPE zif_abapgit_definitions=>ty_diffs_tt it_ids TYPE string_table ) RETURNING rt_diff TYPE zif_abapgit_definitions=>ty_diffs_tt RAISING zcx_abapgit_exception`
  - `zcl_ag2ui5_repo_service=>patch_lstate( iv_lstate TYPE string it_diff TYPE zif_abapgit_definitions=>ty_diffs_tt ) RETURNING rv_lstate TYPE string`: returns `D` (stage `rm`), `A` (stage `add` as added) or `M` (stage `add` as modified). It is called `patch_lstate` rather than the spec's `patch_action` because it returns abapGit's state, which goes straight into `is_status-lstate`. "All lines" is read from `it_diff`, as abapGit's `are_all_lines_patched` does: every row has `patch_flag`.

- [ ] **Step 5: Implement**

`map_diff`: after building `ls_new` and `ls_old`, set the IDs:

```abap
      " the patch ID uses abapGit's numbers, which set_patch_new/_old use too
      ls_new-patch_id = COND #( WHEN ls_diff-result = zif_abapgit_definitions=>c_diff-insert
                                  OR ls_diff-result = zif_abapgit_definitions=>c_diff-update
                                THEN |N{ lv_new_num }| ).
      ls_old-patch_id = COND #( WHEN ls_diff-result = zif_abapgit_definitions=>c_diff-delete
                                THEN |O{ lv_old_num }|
                                WHEN ls_diff-result = zif_abapgit_definitions=>c_diff-update
                                THEN |N{ lv_new_num }| ).
```

(`ls_new` of an unchanged row is reused as the `same` line; its `patch_id`
stays empty because the COND has no match.)

```abap
  METHOD fingerprint.

    " each side hashed on its own, so no two pairs share a fingerprint
    rv_fingerprint = |{ zcl_abapgit_hash=>sha1_raw( iv_local ) }{ zcl_abapgit_hash=>sha1_raw( iv_remote ) }|.

  ENDMETHOD.

  METHOD apply_patch.

    IF it_ids IS INITIAL.
      zcx_abapgit_exception=>raise( `No lines picked` ).
    ENDIF.

    rt_diff = it_diff.
    LOOP AT it_ids INTO DATA(lv_id).
      DATA(lv_side) = substring( val = lv_id len = 1 ).
      DATA(lv_num)  = substring( val = lv_id off = 1 ).
      DATA(lv_hit)  = abap_false.
      LOOP AT rt_diff ASSIGNING FIELD-SYMBOL(<ls_diff>).
        IF ( lv_side = `N` AND condense( CONV string( <ls_diff>-new_num ) ) = lv_num
             AND ( <ls_diff>-result = zif_abapgit_definitions=>c_diff-insert
                OR <ls_diff>-result = zif_abapgit_definitions=>c_diff-update ) )
        OR ( lv_side = `O` AND condense( CONV string( <ls_diff>-old_num ) ) = lv_num
             AND <ls_diff>-result = zif_abapgit_definitions=>c_diff-delete ).
          <ls_diff>-patch_flag = abap_true.
          lv_hit = abap_true.
        ENDIF.
      ENDLOOP.
      IF lv_hit = abap_false.
        zcx_abapgit_exception=>raise( |Line { lv_id } is not a change| ).
      ENDIF.
    ENDLOOP.

  ENDMETHOD.

  METHOD patch_lstate.

    " unchanged rows count as picked: abapGit's are_all_lines_patched
    " counts every row, so a file with unchanged lines is never "all"
    DATA(lv_all) = xsdbool( NOT line_exists( it_diff[ patch_flag = abap_false ] ) ).
    rv_lstate = COND #( WHEN lv_all = abap_true AND ( iv_lstate = `D` OR iv_lstate = `A` ) THEN iv_lstate
                        ELSE `M` ).

  ENDMETHOD.
```

Check `lstate_matrix`'s "all" case: `MODIFY ... WHERE patch_flag = abap_false`
flags every row, including the unchanged one. That is abapGit's rule too: an
added or deleted file has no unchanged rows, so "every row flagged" equals
"every change picked" exactly where it matters.

```abap
  METHOD take_patch.

    IF is_patch-applied = abap_false.
      RETURN.
    ENDIF.
    READ TABLE mt_rows ASSIGNING FIELD-SYMBOL(<ls_row>)
      WITH KEY path = is_patch-path filename = is_patch-filename.
    IF sy-subrc <> 0.
      RETURN.
    ENDIF.

    DELETE mt_patches WHERE path = is_patch-path AND filename = is_patch-filename.
    " every line picked is the whole file, none picked is no patch
    IF is_patch-ids IS NOT INITIAL AND lines( is_patch-ids ) < is_patch-total.
      INSERT VALUE #( path        = is_patch-path
                      filename    = is_patch-filename
                      ids         = is_patch-ids
                      fingerprint = is_patch-fingerprint ) INTO TABLE mt_patches.
      <ls_row>-patched  = abap_true.
      <ls_row>-selected = abap_true.
      <ls_row>-change   = change_text( is_row = <ls_row> iv_picked = lines( is_patch-ids ) iv_total = is_patch-total ).
    ELSE.
      <ls_row>-patched = abap_false.
      <ls_row>-selected = xsdbool( is_patch-ids IS NOT INITIAL OR <ls_row>-selected = abap_true ).
      <ls_row>-change  = change_text( <ls_row> ).
    ENDIF.

  ENDMETHOD.

  METHOD change_text.

    rv_text = SWITCH #( is_row-lstate
                        WHEN `A` THEN `add`
                        WHEN `D` THEN `delete`
                        ELSE `modify` ).
    IF iv_total > 0.
      rv_text = |{ rv_text } - { iv_picked } of { iv_total } lines|.
    ENDIF.
    IF is_row-rstate IS NOT INITIAL.
      rv_text = |{ rv_text } - changed in Git too, pull first|.
    ENDIF.

  ENDMETHOD.
```
