# Diff view: implementation plan

**Spec:** `docs/superpowers/specs/2026-10-01-diff-view-design.md`

Deployment works as in the earlier plans: push branch `feature/diff-view`, then
`agent-pull.py refs/heads/feature/diff-view --package '$ABAPGIT2UI5'`.

## Review focus

- A file that exists only locally, or only in the remote.
- A U (update) row.
- Two changes whose context overlaps.
- A file with CRLF line endings, or trailing whitespace.
- A very large file: only the visible rows are bound.

## Task 1: types, compact and map_diff, test first

- Add `ty_diff_line(s)`, `ty_diff`, `c_line_kind` and `get_diff` to the
  interface.
- Write the tests first and watch them fail, then implement.

## Task 2: service get_diff

- Read the local and remote files, check for binary data, diff, map.
- Smoke test through sapcli with a local change in `$AG2UI5_TEST`.

## Task 3: diff app and the row press in the status app

- `npm run check` must be clean.
- Browser test through UI5 events.
- Screenshot, rendered headlessly.
